# Real Estate Listing Generator & Recommender

### Overview

A system that generates Berlin property listings and provides personalized recommendations using AI. The system creates property descriptions, stores them in a searchable vector database, and matches properties with user preferences.

### Quick Start
1- Set your OpenAI API configuration
os.environ["OPENAI_API_KEY"] = "your-api-key"
os.environ["OPENAI_API_BASE"] = "https://openai.vocareum.com/v1"

2- Run the jupyter notebook
